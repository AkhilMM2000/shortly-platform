# Initial database schema

## User

`User` represents a registered account that can own short URLs.

- `id`: PostgreSQL UUID primary key generated by Prisma.
- `name`, `email`, and `passwordHash`: required account data.
- `email`: unique.
- `createdAt` and `updatedAt`: managed timestamps.

## Url

`Url` represents a shortened URL owned by one registered user.

- `id`: PostgreSQL UUID primary key generated by Prisma.
- `originalUrl` and `shortCode`: required URL data.
- `shortCode`: unique.
- `userId`: UUID foreign key to `User.id`.
- `createdAt` and `updatedAt`: managed timestamps.

## Relationship and indexes

One `User` owns many `Url` records; each `Url` belongs to exactly one `User`. Deleting a user cascades to its URLs. The `Url.userId` foreign key has an index for owner-based queries.

## Migration

The initial schema migration is `init_user_url`.
